# Upstream

The Hyprland plugin in this repository is derived from **[zoan37/hypr-momentum](https://github.com/zoan37/hypr-momentum)** (MIT).

Omarchy packaging adds install/uninstall scripts, opt-in `~/.config/omarchy/mac-scrolling.conf`, registration try/catch (w86 / Hyprland 0.57.2), and `tests/container-hyprpm.sh`.
